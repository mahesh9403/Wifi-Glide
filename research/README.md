# Wi-Fi Glide research

The research brief will answer whether software alone can select among separately named Wi-Fi
networks as the user moves around a building. Findings should cite primary operating-system
documentation where possible and label claims as supported, user-mediated, privileged, or not
available to normal applications.

The planned output will cover:

- platform capability comparison;
- existing operating-system and third-party solutions;
- a hysteresis-based switching policy;
- architecture and decision-flow diagrams;
- risks, test strategy, and a phased proof-of-concept roadmap.
